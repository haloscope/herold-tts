Herold-TTS — Demo-Webservice

Verbinde mit API …

1 · Ansage rendern

Erzeugt pro Ansage drei WAV-Dateien mit der Signature-Stimme: _en, _de und _multiversion (EN + 2 s Pause + DE). Exemplarischer Ablauf: POST /api/render → GET /api/jobs/{id} pollen → Dateien über /api/files abrufen. Alle Endpoints: Swagger UI.

2 · Zu AAC + MP3 konvertieren

Konvertiert alle gerenderten WAVs mit Loudness-Normalisierung (EBU R128, −23 LUFS) zu .m4a und .mp3 (POST /api/convert).

3 · Dateien

Inhalt von data/renders/ und data/final/ (GET /api/files). Anhören direkt im Browser, Download per Klick auf den Namen.
